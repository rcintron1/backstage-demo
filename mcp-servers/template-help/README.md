# Template Help MCP

Local STDIO MCP server that answers how to use this portal's example Software Templates:

- `iphone-app`
- `example-nodejs-template`

## Tools

- `list_example_templates`
- `get_template_usage_guide`
- `compare_example_templates`

## Setup

```sh
yarn install
```

Backstage MCP Chat launches this via `scriptPath` in `app-config.yaml` (Ollama `qwen2.5:7b-instruct`).
